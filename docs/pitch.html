📦 BorrowBox
Full-Stack Asset Sharing & Equipment Lending Platform
Java 21 Spring Boot 3.5 React 18 MySQL 8.0 Docker Compose Cypress E2E GitHub Actions
Value Proposition: BorrowBox replaces disorganized spreadsheets and informal messaging with a secure, auditable, and automated physical asset sharing workflow for university labs, makerspaces, and shared organizations.
🎯 Problem
  • Lost & Unreturned Items: Informal lending via chat leads to misplaced gear, broken accountability, and lost inventory.
  • Zero Real-Time Visibility: Members cannot see what items are currently available, who has them, or when they are due.
  • Spreadsheet Bottlenecks: Manual logs lack access controls, audit trails, and automated overdue tracking.
💡 Solution
  • Live Searchable Catalog: Real-time status indicators (AVAILABLE, BORROWED, ARCHIVED) with multi-field search.
  • Structured Request Workflow: Borrowers submit requests; owners review, approve, reject, or confirm loans with due dates.
  • Automated Lifecycle: Atomic state transitions, overdue calculation, historical logs, and one-click return reconciliation.
🚀 Core Features Implemented
Module Capabilities & Implementation Details
Authentication BCrypt password hashing, stateless HttpOnly JWT cookies (XSS-safe), global exception handling, and React protected route guards.
Inventory Catalog Full item CRUD, category assignment, dynamic multi-attribute search using Spring Data JPA Specifications, and item archiving.
Borrow Requests Request submission with custom notes, owner inbox, approve/reject endpoints, and atomic loan confirmation with binding return dates.
Loan Tracking Active loan monitoring, automated overdue status detection, borrower loan history, and one-click return processing.
User Interface Clean tabbed dashboard (Explore, My Inventory, Requests, Loans), real-time stats overview, and server-side pagination.
